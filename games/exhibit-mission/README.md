# 展示室の並び替えミッション v1.0.0

小学4〜6年生の3人が、1台のパソコンで3枚の依頼を突き合わせて展示を完成させる協力パズル。性別で好みを決めず、実際の児童の反応を確認して使用してください。

## 起動

配布ZIPを展開して `exhibit-mission.html` をChromeまたはEdgeで開きます。リポジトリ内の `index.html` も同じゲームです。保存後の利用にはインターネット接続、ログイン、アプリ、外部ライブラリ、API契約は不要です。個人情報の入力・保存・送信を行いません。

Chromebookでは「ファイル」アプリで保存先からHTMLを開けるか、先生が事前に確認してください。学校の管理設定によってHTML起動・JavaScript・ダウンロード・外部URLが制限されることがあります。制限は回避せずICT担当者へ相談し、必要なら同じHTMLを学校承認のHTTPS静的配信先で配信します。配信先のCSP・ログ・アクセス制限は別途管理者が確認してください。Web版が自動的にオフライン保存される仕組みはありません。

## 操作

作品を1つ選び、入れ替えたい枠を押すと交換します。同じ枠をもう一度押すと選択を取り消せます。相談してから「3枚の条件を確かめる」で各条件の成立を確認します。マウス・タッチ、またはTab移動とEnter/スペースで操作できます。

ヒントは3段階。2段階目は正しい作品を左端へ自動で移し、3段階目は見本の並びを表示します。「見本を見て進む」でパスできます。

## 3人で約5分

1. 説明40秒：席順に1番・2番・3番とし、3人が1枚ずつ依頼を確認します。
2. 練習40秒：置き方と確認の方法を一緒に試します。
3. 本番2問、各約80秒：各自の条件を突き合わせて配置を相談し、次の問題で操作役を交代します。
4. 鑑賞約1分：完成した展示を見て、どの条件が決め手になったか、話したい人だけ共有します。

約5分は設計上の目安で、実児童での所要時間は未確認です。急かさず、必要ならヒントを使ってください。点数・個人順位・誤答への罰はありません。

## 参加しやすくする声かけ

「この並びで、ほかの2枚の依頼もかなったかな。一緒に見てみよう」「次の置き方を、指差しでも教えてもらおうか」。発言や笑うことは強制しません。パス・見学・共同担当を認め、ほかの児童や先生が引き継げます。

全員が同じ画面を見るため、1人で全条件を読むことは防げません。3人が必ず相談することを技術的に保証するものではなく、担当・確認・交代によって相談を促す設計です。
