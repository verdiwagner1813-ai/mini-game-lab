## 再実行

ロジックはNode標準機能だけで実行可能。ブラウザテストは開発検証用で、ゲーム利用者の追加ソフトを要求しない。

```sh
node tests/exhibit-logic.cjs
PLAYWRIGHT_MODULE=/path/to/playwright-core CHROMIUM_PATH=/path/to/chromium node tests/exhibit-browser.cjs
```

ブラウザテストのサーバは127.0.0.1の自動割当ポートだけで待受け、検証終了時にサーバとブラウザを終了する。制限環境では権限が必要になる場合がある。
